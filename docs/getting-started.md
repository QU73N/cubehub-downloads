# Start practising with CubeHub

1. Open [CubeHub](https://cubehubs.netlify.app) or install the Android/Windows preview from this repository's releases.
2. In **Learn**, choose a puzzle guide, a course, or an algorithm set. Puzzle, method and set selectors are separate.
3. In **Timer**, choose a puzzle and session. Follow the scramble, compare the target, then use touch or the spacebar. Focus view keeps the timer prominent.
4. Choose **Race a bot** to watch a simulated partner follow CFOP or a beginner method. These are practice results, not competitive rankings.
5. Sign in for account services and Smart Coach questions. For existing local practice, choose its destination once in **Settings → Practice sync**.

## Useful habits

- Save comparable solves in the same event/session. Keep penalties visible.
- Use **Show 10 more** when you need older timer results; export still includes saved session records.
- After a tutorial, practise one takeaway. Solve footage, entertainment and discussions have their own video shelves.
- Record real stage data for specific coaching. A PB or total time alone cannot reveal a weak layer.

## Updates and access

Apps check the published release information and offer an update when a newer version is available. Installation remains an operating-system action.

Free Coach access is five answered questions per UTC day. Premium has no daily question cap and can be granted by an administrator under **Members → Manage → AI Premium access**. Normal request rate limits still prevent accidental floods. Offline learning guides and local insights remain available; account questions need connectivity.

The APK and Windows EXEs are preview builds. Real phone, camera, Bluetooth and installer acceptance should be checked on the devices you use.
